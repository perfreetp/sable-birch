# 城市空中交通航迹推演工具（UAM Trajectory Simulator）

基于 **TypeScript + Svelte 4 + three.js + troika-three-text** 的低空空中交通三维航迹推演与冲突告警工具。

## 功能

- **航迹载入与插值**：载入 JSON 航迹文件，按航迹点时间做分段线性插值，逐帧驱动飞行器运动；速度由相邻航迹点差分得到，机头朝向随速度方向实时更新。
- **渐隐轨迹线**：每架飞行器尾部保留 20 秒历史轨迹，自定义 Shader 按顶点年龄做二次方渐隐，拖动时间轴时按窗口重采样重建。
- **三维文字标签**：troika-three-text 渲染编号与高度（米），标签按相机距离自动缩放保证屏上字号恒定，并通过屏幕空间迭代推挤算法消除重叠；冲突时标签变红。
- **冲突检测**：每帧对所有活跃飞行器做两两水平/垂直间隔判定（O(n²)），同时低于阈值时两机之间绘制红色告警连线、机身与标签变色，冲突记录包含起止时刻、持续时长、最小水平间隔。
- **时间轴回放**：播放 / 暂停、1×/2×/4× 三档倍速、进度条拖动；拖动时全部航迹在目标时刻同步重算位置，并对 `[0, 目标时刻]` 以 0.5s 步长全量重扫，保证冲突统计在来回拖动后始终一致。
- **侧边列表**：飞行器按累计冲突数降序排列（活动冲突优先、编号次序兜底），点击列表行选中并平滑聚焦相机；3D 视口中点击航模同样可选中。
- **阈值可调**：水平/垂直安全间隔阈值支持运行时修改，修改后冲突记录立即全量重建。
- **结果导出**：一键导出完整推演结果 JSON（航迹 + 冲突 + 阈值 + 时刻），或仅导出带 BOM 的冲突记录 CSV（Excel 可直接打开）。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5173
npm run build      # 生产构建
npm run check      # 类型检查（0 错误标准）
npm run test:logic # 纯逻辑冒烟测试（插值/冲突/重扫/排序，12 项）
```

启动后默认载入内置演示场景（10 架飞行器，含两组刻意构造的冲突对：t≈40s 对头穿越、t≈62s 汇聚穿越）。

## 航迹数据格式

载入的 JSON 文件结构（也兼容本工具导出的结果文件，自动识别其中的 `tracks` 字段）：

```json
{
  "name": "场景名称",
  "horizontalThreshold": 80,
  "verticalThreshold": 30,
  "aircraft": [
    {
      "id": "UAM-01",
      "type": "EH216-S",
      "points": [
        { "t": 0,    "x": -600, "y": 150, "z": 0 },
        { "t": 40,   "x": 0,    "y": 150, "z": 0 },
        { "t": 80,   "x": 600,  "y": 150, "z": 0 }
      ]
    }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `t` | 航迹点时刻（秒，相对推演起点，无需从 0 开始） |
| `x / z` | 平面东向 / 北向坐标（米） |
| `y` | 高度（米） |
| `horizontalThreshold` | 水平安全间隔阈值（米），缺省 80 |
| `verticalThreshold` | 垂直安全间隔阈值（米），缺省 30 |

载入时会做完整校验：结构缺失、字段非数值、编号重复等均会给出中文错误提示。

## 目录结构

```
src/
├── lib/
│   ├── types.ts            # 全部领域类型
│   ├── interpolate.ts      # 二分航段定位 + 线性插值 + 航向/速度计算
│   ├── simulation.ts       # 时间轴状态机、冲突检测、拖动全量重扫
│   ├── sampleData.ts       # 内置演示场景生成 + 载入校验
│   ├── exportData.ts       # JSON / CSV 导出
│   ├── stores.ts           # Svelte 响应式状态
│   └── scene/SceneManager.ts  # three.js 场景、航模、拖尾、标签、告警线、拾取、相机
├── components/
│   ├── Viewer3D.svelte     # 3D 视口与 requestAnimationFrame 主循环
│   ├── Timeline.svelte     # 播放控制与拖动时间轴
│   ├── Sidebar.svelte      # 飞行器排序列表 / 冲突记录 / 阈值设置
│   └── Toolbar.svelte      # 载入与导出
└── App.svelte              # 整体布局与模块编排
```

## 关键设计说明

- **冲突状态机**：以排序后的双机编号为稳定 key，新冲突建记录、持续冲突刷新结束时刻与最小间隔、本帧未触发则闭合记录；闭合记录保留用于统计与导出。
- **拖动一致性**：进度条跳转不是简单跳帧，而是以固定步长重放目标时刻之前的全部时间片后重建冲突 Map，因此任意方向反复拖动得到的累计冲突统计都可复现。
- **标签防重叠**：每帧将标签锚点投影到屏幕像素坐标，按深度排序后做多轮轴对齐推挤，再把像素位移换算回相机右/上方向的世界偏移。
- **性能**：UI 统计以 10Hz 节流刷新避免每帧触发 Svelte 重渲染；拖尾使用预分配 TypedArray + 环形压缩，无逐帧内存分配。
