# 船舶靠泊姿态模拟系统

基于 **TypeScript + Svelte 5 + three.js + postprocessing** 的船舶靠泊全过程仿真系统，
覆盖泊位与船型配置、靠泊动力学预演、系缆受力分析三大模块。

## 功能总览

### 模块一：参数设定
- **船型库**：内置集装箱船 / 散货船 / 油轮 / 杂货船 4 种预设，按船长、船宽、型深、吃水、方形系数
  实时参数化生成三维船体（21 站横剖面网格 + 上层建筑 + 货舱 + 导缆孔）
- 自动派生排水量、初稳心高 GM、横摇/纵摇固有周期、受风面积等水动力参数
- **泊位库**：岸壁、护舷（数量/刚度/阻尼/摩擦/凸出长度）、系缆桩布置可编辑
- **环境工况**：靠泊角度、法向/沿壁速度、横风、横流、初始位置、张力报警阈值
- 所有配置自动持久化到 `localStorage`，支持导出 JSON 文件 / 复制 JSON 分享 / 导入配置

### 模块二：靠泊预演
- 3DOF 平面操纵（纵移、横移、首摇）+ 横倾、纵倾、升沉共 6 自由度姿态积分
- 风载荷、流载荷、水动力阻尼、附加质量按 MMG 类经验系数建模
- 船体接触护舷后按各接触点分布计算非线性法向反力与摩擦力，产生偏转力矩
- 接触瞬间迸发浪花粒子，护舷按受力高亮
- 时间轴回放（0.25×~4× 倍速、拖动定位），三张同步曲线：
  姿态角（横倾/纵倾/首向）、运动（沿壁位置/离岸距离/升沉）、受力与速度
- 靠泊完成后输出沿壁偏差、离岸间隙、首向角偏差、最大护舷反力、挂缆时刻等 KPI

### 模块三：缆绳受力
- 甲板布置 6 根缆绳（头缆×2、尾缆×2、艏艉横缆），端点坐标与材料参数可编辑
- 每根缆绳按两端点距离与双斜率弹性拉伸模型计算张力，自动绞车模型维持预张力
- 3D 缆绳按张力渐变色显示（绿 → 黄 → 橙 → 红），超阈值时高频抖动并闪烁
- 实时张力表（张力、应变、破断利用率、当前长度、峰值）与张力历史曲线（含阈值线）
- 靠泊完成汇总各缆终值 / 峰值 / 报警次数

### 场景与渲染
- three.js 参数化船体、岸壁、胶囊护舷、系缆桩、海面
- 海面基于 `Reflector` 平面反射 + 自定义波浪着色器（泡沫圈、波峰明暗）
- postprocessing 管线：Bloom（浪花/报警发光）+ FXAA 抗锯齿
- OrbitControls 自由视角、跟随船位、一键复位

## 物理模型说明

- **积分器**：固定步长 0.02s，每步 4 子步；0.1s 等间隔采样供回放与绘图
- **护舷**：`tanh` 软化的非线性弹簧 + 阻尼，力上限 6 倍刚度防止硬接触发散
- **缆绳**：破断应变 4% 以下线性弹性、以上刚度折减 35%（材料软化/悬垂效应）；
  松弛段由自动绞车提供指数衰减的预张力，避免系泊后完全松脱
- **横摇/纵摇**：基于 GM / GML 的恢复力矩 + 线性阻尼 + 波浪激励
- **挂缆时机**：首次护舷有效接触瞬间自动挂缆并按预张力标定原长
