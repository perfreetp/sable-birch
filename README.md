# 场桥吊装包络预演工具

面向港口堆场中控操作员的场桥(RTG)吊装作业预演工具。技术栈: TypeScript + React + three.js + three-mesh-bvh。

## 运行

```bash
npm install
npm run dev    # http://localhost:5173
npm run build  # 生产构建
```

## 功能

- **三维场景**: 程序化生成堆场箱区(A/B 两区, 在场箱量 ≤2000)、轨道梁、集卡车道与场桥模型; 轨道旋转/平移/缩放(左键旋转、右键平移、滚轮缩放)。
- **四轴控制**: 大车行走 / 小车横移 / 起升高度 / 吊具回转, 支持面板滑杆与场景内拖拽(拖吊具=起升, Shift+拖吊具=回转, 拖小车=横移, 拖大梁/支腿=大车)。
- **吊具规格**: 40 尺 / 20 尺一键切换。
- **包络体**: 按吊具外扩净空阈值实时生成半透明包络体(绿色=安全, 红色=侵入)。
- **BVH 净空检测**: 包络体与邻近箱体、轨道梁、车道缘石做 three-mesh-bvh 穿透检测; 净空不足时相交面染红, 场景内显示最小间距数值标签与最近点连线; 净空阈值默认 0.5m 可调。
- **左侧面板**: 四轴实时读数、最小间距、净空余量、侵入面数、箱信息(点击箱体查看箱号/贝位/堆存层高)。
- **辅助线**: 点击吊具循环切换 俯视投影 → 侧视投影 → 关闭。
- **右侧记录**: 三组预演姿态(参数+净空结果), 支持回放(平滑过渡动画)、勾选对比、删除, 可导出 JSON 姿态文件供班前交底。

## 结构

- `src/yard.ts` — 堆场布局与箱区数据生成
- `src/SceneManager.ts` — 三维场景、场桥模型、BVH 碰撞检测、拖拽/拾取交互
- `src/components/` — 左右面板
- `scripts/verify-bvh.mjs` — 净空算法独立数值验证 (`node scripts/verify-bvh.mjs`)
