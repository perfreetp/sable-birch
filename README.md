# 陶俑残片拼合工具

出土陶俑残片的虚拟复原工作台：导入多片残片网格后逐片摆放、按断口特征点粗对齐、
沿断口法向微调，最后对两片或多片执行实体布尔合并，并统计拼缝缝隙宽度分布、检查网格自交、导出任一网格与位姿清单。

**技术栈**：TypeScript · React 19 · three.js · manifold-3d（WASM 实体布尔）· three-mesh-bvh（距离/自交加速）

## 启动

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # 类型检查 + 生产构建
npm run preview
```

首次打开会自动载入一套程序化生成的中空陶俑示例（10 片水密网格，单位 mm），
可直接点顶部「对照原位」看到正确复原结果；初始为散开姿态，可自行拼合。

### 视角与选择

| 操作 | 说明 |
| --- | --- |
| 左键拖拽空白 | 旋转视角（OrbitControls） |
| 右键 / 中键 | 平移 / 缩放 |
| 单击残片 | 选中；双击取景 |
| 滚轮 | 缩放 |

### 摆放：0.5° 旋转精度、1 mm 平移步进

- **平移**（`W`）：拖动三轴手柄时按 **1 mm** 吸附；左侧面板可直接输入坐标，`±X/±Y/±Z` 按钮每次 1 mm；`← →` 键微调 1 mm（按住 `Shift` 为 10 mm）。
- **旋转**（`E`）：拖动旋转环时按 **0.5°** 吸附；`X / Y / Z`（或 `1 2 3` 键）限制为单轴旋转；`← →` 每次 0.5°。
- 每个残片独立保存位姿（位置 + XYZ 欧拉角），互不影响。

### 拖动时实时显示与相邻片的最近距离

- 拖动过程中（节流 60 Hz）以及选中片、位姿变化后立即更新；
- 视口左下角 HUD 显示最近距离（mm）与对应的两片名称；
- 视口中用虚线连接两片的最近点，并用青色圆点标出位置。

距离查询用 two-mesh BVH 的 `closestPointToGeometry` / `closestPointToPoint` 加速：
拖动时用表面采样点做点-面查询（快），右下角「距离探针」可开关。

### 断口三点粗对齐 + 沿法向 0–20 mm 微调

1. 在残片列表中选中「移动片」，点「设为对照片」把另一片设为「固定片」；
2. 「点选固定片 3 点」「点选移动片 3 点」，在视口断口上一一对应地点选特征点；
3. 「计算并应用粗对齐」——用 Horn 四元数法求最优刚体变换（Horn，Jacobi 特征分解），
   面板给出残差 RMSD；6 个点全部精确对应时 RMSD ≈ 0；
4. 「法向微调」滑块沿三个固定点拟合法向平移移动片 0–20 mm 用于压合或留缝。

### 实体布尔合并

- 合并前先对每片做自交检测（BVH 自相交遍历 + 三角形 SAT 精确相交），
  问题面在视口中高亮为红色面片 + 白热线框 + 红色标记点，面板列出各片问题面数；有自交时阻止合并。
- 合并本身在 Web Worker 中执行 manifold-3d 的 `Manifold.union`，界面不卡顿；
- 合并结果自动剔除布尔残渣（零体积薄壳），得到单一连通实体；
- 合并后再次自交检测：**穿插**计为问题面（高亮），布尔切片留下的共面薄片不计入。

### 拼缝缝隙宽度分布

拼缝缝隙定义：两片在接触带内、按 1 mm 空间块统计的两片表面最近间距。

1. 在两片表面按三角形面积加权采样；
2. 用 BVH 求每个采样点到对方表面的最近距离，只保留 ≤ 捕获半径（默认 1.6 mm）的接触带采样；
3. 接触带按 1 mm 见方的空间块分箱，每块取最小距离 → 该处拼缝宽度；
4. 汇总所有块，给出中位数 / 均值 / P90 / P99 / 最大值、直方图、贴合率（≤ 阈值的块占比）。

多片合并时按「包围盒间隙 ≤ max(3×捕获半径, 2 mm)」筛出相邻片对，逐对统计后合并。
合成数据校验：两块平行板间隙 0.3 / 0.5 / 1.0 / 1.5 mm 时中位数分别为 0.300 / 0.500 / 1.000 / 1.500 mm。

### 透明度与显隐

- 每片「单片透明度」0–100%，以及「全局透明度」；
- 列表最左的 ◉/○ 按钮切换单片显隐（`H` 键切换选中片）；
- 视口「透视」按钮一键把全局透明度切到 45%，便于观察内部贴合情况。

### 导出

- **合并 STL / OBJ**：合并后的单一网格（世界坐标，二进制 STL 或 ASCII OBJ）；
- **导出压缩包**：`merged.stl` + `merged.obj` + `pose-manifest.json` + `seam-gap-report.json` + `README.txt`；
- **位姿清单 JSON**：每片残片的 `position`、`rotation`（XYZ 欧拉角，度）、4×4 变换矩阵，
  以及精度设定、对齐记录、合并记录与缝隙统计；
- 「复制」把同一份 JSON 复制到剪贴板。

## 已知限制

- 网格必须是封闭实体（水密、无自交）才能参与实体布尔；导入时自动重新焊接顶点，
  但不会自动补洞。若合并时报 `Not manifold`，说明该片网格有孔洞或非流形边。
- 三点对齐要求两组点严格一一对应；点的顺序错位会得到错误位姿（RMSD 会明显偏大，可据此判断）。
- 示例残片由程序化 Voronoi 分割生成，接缝本身带有 ~0.2 mm 的网格化间隙，
  因此贴合状态下拼缝中位数不会精确为 0；合成平面数据可校验到 0.001 mm 精度。
