# 低空起降场视景评估工具

面向低空起降场选址团队的 3D 视景评估工具:在地形与建筑场景中放置起降场,设定 3 个进近方向,实时评估进近视锥与建筑物的穿透关系,并以热力网格展示净空覆盖。

## 技术栈

- **TypeScript + Vue 3**(组合式 API)
- **Babylon.js**,优先 **WebGPU 引擎**(`WebGPUEngine`),环境不支持时自动回退 WebGL
- Vite 构建

## 功能

| 功能 | 说明 |
| --- | --- |
| 场景 | 程序化地形(确定性高度函数)+ 确定性随机建筑群(含一片高层核心区) |
| 起降场 | 点击「移动位置」后点击地面放置;滑杆调整旋转角;标高自动取地形高度 |
| 罗盘 | 拖动 3 个彩色手柄设定进近方位角,也可直接输入度数 |
| 进近视锥 | 每个方向生成截锥体(下滑角、扩散半角、长度可调),半透明渲染 + 下滑道虚线 |
| 穿透检测 | 建筑顶面 9 点采样 vs 净空面,穿透建筑红色高亮,面板列出穿透深度、顶高、面高、距离 |
| 热力网格 | 地面 20m 网格,按净空面离地高度分 5 档着色;悬停网格显示覆盖高度与覆盖视锥数 |
| 视角 | 一键俯视(正交俯视轨道相机)/ 进近视角(相机置于视锥远端,沿下滑道看向起降场) |
| 导出/载入 | 评估结果 + 起降场参数导出为 JSON;载入后恢复全部参数并自动重算 |

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/
```

> WebGPU 需要 Chrome/Edge 113+;不满足时界面右上角会显示 WebGL 回退标识。

## 坐标与几何约定

- 世界坐标:X 东、Z 北、Y 上,单位米;方位角 0°=北,顺时针为正。
- 净空面(下滑道面)自场坪边缘起,按下滑角上升、按扩散半角展宽;穿透深度 = 建筑顶高 − 该点净空面海拔。
- 热力网格「覆盖高度」= 覆盖该网格的所有视锥净空面中,距地面最近的高度。

## 导出文件格式

`vertiport-assessment` v1 JSON:起降场位置/旋转/标高、3 个进近方位角、视锥参数、穿透障碍物清单与热力统计。载入时恢复参数并实时重算。
