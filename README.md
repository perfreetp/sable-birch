# Aeroscope · 低空航路气象体积渲染

面向低空无人机航路的雷暴单体与云底高度三维分析工具。加载分帧气象体数据后，以体积光线步进渲染对流单体，
配合时间序列推演、密度阈值分级、航路垂直剖面与逐航段能见度导出。

技术栈：**TypeScript · Vue 3 · three.js · postprocessing · Vite**

## 快速开始

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 生产构建到 dist/
npm run preview    # 预览生产构建
```

首次进入时会在后台生成 24 帧体数据并逐块写入浏览器存储（IndexedDB），
顶部进度条结束后时间轴上的帧标记会全部点亮；之后的会话直接从缓存装载。

## 三个模块

按顶栏按钮或键盘 `1` / `2` / `3` 切换，`Space` 播放/暂停。

### 体积视图 `VOLUME`
- 体数据网格 **96 × 48 × 96**，按 **6 × 3 × 6 个 16³ 分块**组织，逐块上传为 `Data3DTexture`。
- 光线步进在**后处理阶段**完成（`VolumetricCloudsEffect`）：读取场景深度、逐像素重建视线，
  在体积盒内做 110–150 步采样，含日照方向二次步进、powder 项与多层散射近似。
- **3 档密度阈值**切换云体通透度，并同时切换配色：
  | 档位 | 阈值 | 说明 |
  | --- | --- | --- |
  | 稀薄 | EDT-0.14 | 保留砧状与降水拖尾，冷灰蓝配色 |
  | 标准 | EDT-0.26 | 经典对流色阶，青色底 → 琥珀中层 |
  | 致密 | EDT-0.40 | 仅留致密核心，暖色危险色阶 |
- **云底高度面**：按分析网格插值生成高度场网格，等高线分层着色，无云处自动淡出。
- **地形底图**三选一：暗色地形 / 高程分层 / 等高线。三套底图均由高程场程序化烘焙
  （多尺度山体阴影 + 颗粒纹理）。
- **航路高亮**：航路基线、高度带护栏与半透明带体；开关即时重烘焙几何。
- **体积雾强度**滑块调节大气透视强度（场景雾 + 后处理距离雾）。
- 右侧面板显示分块缓存占用与 24 帧时间轴状态。

### 航路编辑 `ROUTE`
- 航路点列表可拖动排序，逐个编辑名称、东西/南北偏移与**高度带下界/上界**。
- 右侧编辑器带高度带标尺，并标注地面高程与**最低安全高度 MSA**（地形 + 300 m，向上取整到 50 m）。
- 三维视图中双击地面可拾取最近航路点并联动选中。
- 航路段的长度、方位角实时重算。

### 剖面分析 `SECTION`
- 沿航路做垂直剖面（**512 × 144** 采样），叠加**能见度色带**、**最低安全高度线**、
  高度带与云底高度线。
- 悬停读取任意点的距离 / 高度 / 能见度 / 体密度 / 云底 / MSA。
- 航路段汇总表按带宽内统计给出「畅通 / 关注 / 冲突」状态。
- 三维场景中同步呈现同一张剖面切片（独立渲染通道叠加在体积云之上）。

## 导出

| 文件 | 内容 |
| --- | --- |
| `aeroscope-visibility-<时刻>.csv` | 逐航段采样点：`leg_index, leg_label, distance_m, lon, lat, altitude_m, density, precip, visibility_m, cloud_base_m, msa_m` |
| `aeroscope-section-<时刻>.json` | 元数据（分析时刻、密度档位、域范围、航路点）+ 逐航段剖面曲线与全部采样点 |
| `aeroscope-section-<时刻>.png` | 当前剖面图 |

导出全部与实际显示帧一致，并随密度档位、航路编辑与时间帧更新。

## 体数据与缓存

气象场为**程序化合成**的 12.8 km × 12.8 km × 7.2 km 分析域（未随附真实探空），
包含 6 个带砧状云顶、螺旋上升气流与雨幡的对流单体，以及低层积云。每帧 4 分钟，共 24 帧。

- 生成：`src/lib/weather.ts`
- 缓存：`src/lib/volumeCache.ts`，IndexedDB 中每块一条记录（`epoch:frame:chunk`），
  记录携带数据版本号，模型变更时自动失效重建；私有模式下自动降级为内存缓存。

## 目录结构

```
src/
  lib/
    weather.ts        分析域、单体模型、逐帧烘焙、三线性采样、能见度模型
    volumeCache.ts    IndexedDB 分块纹理缓存
    section.ts        剖面构建、逐航段统计、导出采样点
    sectionCanvas.ts  剖面 2D 绘制（图表 / 三维幕布共用）
    scene/
      terrain.ts      地形网格与三套底图烘焙
      weatherScene.ts three.js 场景、体积云效果、后处理链、剖面幕布
    shaders.ts        体积云 GLSL、密度色阶
  components/         三个模块面板、顶栏、时间轴
  store.ts            应用状态、帧装载、剖面重建、导出
```
